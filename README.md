# 游戏作品集

这里收录我的游戏设计、战斗系统拆解与游戏经历材料，面向游戏岗位作品展示。

## 项目演示

### TurnBase2

第三人称高机动探索与队伍制回合战斗结合的角色扮演游戏设计。核心体验包括立体场景探索、主动接敌、行动条回合战斗、元素弱点、实时格挡/闪避、QTE 与角色构筑。

[阅读《TurnBase2》游戏设计文档](./TurnBase2_游戏设计文档.md)

### 鸣潮玩法复刻
基于 UE C++ 与蓝图，复刻《鸣潮》的探索运动、秧秧角色战斗及 Boss 对战，覆盖角色控制、技能结算、战斗反馈与镜头表现。
